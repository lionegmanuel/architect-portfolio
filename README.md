# Manuel Lione - Principal AI Systems Architect & Full-Stack Portfolio

Showcase técnico interactivo y catálogo de arquitectura de software para producción, motores algorítmicos, sistemas de IA deterministas e infraestructura full-stack.

## Resumen Ejecutivo

- **Fundador / Tech Lead:** Manuel Lione (`lionegmanuel`)
- **Especialidad:** Sistemas de IA con Guardrails Deterministas, Streaming UI de Alta Frecuencia, Conciliación Financiera y Automatización de Procesos Críticos.
- **Stack Principal:** TypeScript, React 19, Next.js 15, Node.js, Python, Tailwind CSS, Vite.

## Proyectos Destacados en el Showcase

1. **whatsapp-agent-guardrails:** Middleware determinístico de seguridad, anti-alucinaciones y anti-ruido para agentes LLM en WhatsApp. Latencia media < 4.2ms, 194/194 tests pasando.
2. **financial-stream-dashboard-core:** Dashboard financiero modular con streaming SSE en tiempo real sobre Next.js 15 App Router y React 19.
3. **fuzzy-reconciliation-engine:** Motor algorítmico de conciliación bancaria y matching difuso (Levenshtein, Jaro-Winkler) con capacidad para 10.000 transacciones/segundo.
4. **dentflow-clinical-guardrails:** Validación clínica determinista de 4 fases y protocolos sanitarios para odontología y salud.
5. **docuflow-b2b:** Motor de validación y procesamiento estructurado de documentos tributarios y comerciales B2B.
